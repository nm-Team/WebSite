nmTeam launches nmBot+, an exclusive paid plan tailored for nmBot users and groups who need more advanced features.

nmBot+ is launched with more than 20 new features, covering multiple advanced scenarios such as group join verification, group management, keyword replies, etc.

In the group, nmBot+ mainly includes the following new features:

- Administrator authority control: As the owner of the group, control other administrators' modification permissions to various nmBot configurations.
- Lower restrictions: The number of keyword replies and scheduled tasks has increased, the number of daily replies in the Proper Warm Up has increased, and the number of message templates that can be set for some functions has increased.
- Customized spam rules: Customize the rules for messages and users that are considered spam.
- Group join verification: Add custom text, customize the deletion time of verification messages, and enjoy more customized options for timeout time and ban duration.
- New member authority restrictions: Limit the categories of messages that new members can send in the group.
- Keyword replies: Warn users who send specified keywords.
- Scheduled tasks: Send scheduled messages in the group.
- Limit group members to send commands: customize the commands to be enabled in the group.
- Customize command list: freely select the bot commands displayed in the group input field.
- Call group administrator: customize the keywords for calling group administrators and receive notifications in private messages.

In order to make advanced features affordable for more groups, nmBot+ provides groups with lower subscription prices: 83% of active groups can subscribe to nmBot+ for only $0.4 per month.

nmBot+ is available for purchase in the nmBot panel. You can open the nmBot panel in the Telegram mini app and pay with Telegram Stars. Groups with more than 1,000 members can receive a 15-day free trial in the panel.

\* All functions are subject to actual use and may be adjusted according to actual conditions.
