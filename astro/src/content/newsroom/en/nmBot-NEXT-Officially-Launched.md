*June 14, 2024*— nmTeam officially launched nmBot NEXT today.

nmBot NEXT includes dozens of new features, including:

- [Message Templates](https://t.me/nmbotchannel/321) provide a new way for preset messages, fully upgrading [multiple features supporting various types of messages](https://t.me/nmbotchannel/322), and fully integrating features such as keyword replies, group entry verification, and lockdown mode.
- New channel-specific features, such as [automatic replies to channel posts](https://t.me/nmbotchannel/328), [automatic text formatting enhancements](https://t.me/nmbotchannel/332), and automatic addition of buttons to posts.
- Support for [Telegram business bot features](https://t.me/nmbotchannel/330): [business keyword replies](https://t.me/nmbotchannel/330) provide group-level customization options for business users.
- Comprehensive optimization of the nmBot panel account experience: supports maintaining login status, [simultaneous login of multiple accounts](https://t.me/nmbotchannel/355), and [login via nmTeam account](https://t.me/nmbotchannel/356).
- Several group features have been optimized: keyword reply and lockdown mode settings now have independent switches, [lockdown mode supports setting operation dates](https://t.me/nmbotchannel/326), group whitelist settings and panel view have both been optimized, [group entry verification now smoothly supports join requests](https://t.me/nmbotchannel/345), and [harassment interception supports acknowledgment](https://t.me/nmbotchannel/341).
- The [new command list added to the nmBot panel](https://t.me/nmbotchannel/324) and harassment interception record query feature provide new methods for users to get help.
- Harassment interception feature optimized to more effectively reduce the probability of false bans; users now have a new process to report issues with the harassment interception feature.
- More new features and optimizations can be found in the update log of the nmBot NEXT preview version.

We hope these features bring a smoother experience to our users. In the future, nmBot NEXT will introduce more features to provide more assistance to our users.

If you encounter any issues or have any feedback while using nmBot NEXT, please feel free to contact [nmTeam Support](https://nmteam.xyz/support) for help.
